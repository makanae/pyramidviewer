Information Pyramid 3D Viewer

Files:
- index.html
- pyramid_metadata.json

Usage:
1. Extract the ZIP.
2. Serve the folder with any simple HTTP server, or upload the folder to a static web host.
3. Open index.html in Android Chrome.
Internet access is required for the Three.js library loaded from jsDelivr.

Controls:
- One-finger drag / mouse drag: rotate
- Pinch / wheel: zoom
- Two-finger drag / right drag: pan
- Tap node: details
- Layer checkboxes: show/hide L1-L5
- Opacity slider: translucent level planes
- Labels: automatic LOD for L4.2/L4.3
